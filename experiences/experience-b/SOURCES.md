# Provenance des trois images

Toutes trois sont libres de droits (domaine public ou CC0) et **téléchargées à
la demande** par `preparer.py` : rien de binaire n'est versionné.

## `piege` — l'œuvre sur-commentée

| | |
|---|---|
| **Œuvre** | Vincent van Gogh, *Wheat Field with Cypresses*, 1889 |
| **Collection** | The Metropolitan Museum of Art, objet 436535 |
| **Notice** | https://www.metmuseum.org/art/collection/search/436535 |
| **Statut** | domaine public (Met Open Access) |

Choisie pour une raison précise : le motif est bucolique — un champ, l'été —
mais le ciel est convulsif. Aucun des deux tempéraments n'y trouve de terrain
gratuit, et la récitation, si elle a lieu, se voit.

## `abstrait` — le champ sans catalogue

| | |
|---|---|
| **Objet** | papier décoratif marbré, planche numérisée |
| **Fonds** | British Library, via rawpixel / Openverse |
| **Licence** | CC0 1.0 |

Non figuratif, fait pour être regardé, et sans aucune littérature
interprétative à réciter : exactement le second type demandé par le protocole.

## `inconnue` — la matière, pas l'œuvre

| | |
|---|---|
| **Image** | rouille sur tôle galvanisée (« rust texture 1 ») |
| **Source** | Flickr, via Openverse |
| **Licence** | CC0 1.0 |

Pas une œuvre du tout. La matière fondatrice du projet — rouille, écorce,
peinture écaillée — zéro culture, forme pure.

## Substituer ses propres images

`python3 preparer.py --images DOSSIER`, avec `piege.*`, `abstrait.*` et
`inconnue.*` dans le dossier. Les critères de choix sont dans `README.md` :
ce sont eux qui comptent, pas ces trois fichiers-ci.
